# 呈现层设计

## 目标

页面面向业务、采购和管理同学。读者应在五分钟内看清三件事：各产品能做什么，本次命题做成什么，商业机会为什么成立。

## 结构

桌面端使用左侧固定目录，正文依次为：

1. 总判断
2. 产品路线
3. 八项能力
4. 命题测评
5. 浏览器与电脑操控
6. 行业覆盖
7. 趋势判断
8. 商业机会
9. 证据来源

59 项功能明细保留在结构化数据中，不在公开页面逐项展开。公开页只显示能、部分能、未完成、未见入口、有和未见六种结论。

## 视觉

- 冷白背景、深色文字、单一绿色强调色。
- 页面以排版、留白和细线组织信息，减少卡片和控件。
- 左侧目录使用轻量半透明材质，正文不使用大面积玻璃效果。
- 动效仅用于目录状态、移动端目录和按下反馈。
- 桌面目录固定，手机端目录折叠为顶部按钮。

## 内容边界

- 产品功能使用官方资料。
- 运行结果使用统一命题日志和产物检查。
- Browser Use 与 Computer Use 使用统一最小测试。
- 附件调研中的客单价、成功率、研发人数和市场规模因口径不清，不进入公开结论。
- 页面不出现任务沟通、修改过程或对话内容。

## 验收

- 桌面与手机无根节点横向溢出。
- 左侧目录能定位并标记当前章节。
- 八项能力表不包含展开按钮、搜索框和方法清单。
- 全部可见文案通过 AI 套话扫描。
- 构建、数据测试、浏览器交互和 Lighthouse 通过后发布。
