# 呈现层改版说明

## 读者与目标

页面面向需要了解办公 Agent 的业务、运营、采购与管理同学。读者先看到产品差异和实测结果，再按需展开功能、行业与来源。运行日志、连接器版本和文件校验保留为证据，不作为首页叙事主体。

## 信息结构

1. 一页结论：三组产品组合的当前定位、最小实测结果和证据边界。
2. 功能矩阵：按 Agent、执行环境、办公交付、协同、治理和可观测性筛选。
3. 测评 1：呈现统一任务的完成时间、产物、来源、重试和生态闭环。
4. 测评 2：直接给出浏览器、电脑操控和客户端内浏览器结论。
5. 行业覆盖：区分命名客户、官方场景和能力推断，避免把生态客户直接等同于 Agent 客户。
6. 商业机会：说明买方、价值、成立条件和风险。
7. 来源：每条结论可回到官方资料、实测记录或第三方观察。

## 视觉与交互

- 浅色为主，跟随系统深色模式，单一蓝绿强调色。
- 固定顶部导航使用轻量半透明材质，正文不套多层卡片。
- 产品切换、功能筛选和来源展开提供即时反馈，动效只用于状态变化。
- 手机端改为单列，功能矩阵允许横向滚动，关键结论不依赖悬停。
- 遵循减少动态效果与减少透明度偏好。

## 文案原则

- 先写观察到的事实，再写适用条件。
- 不用“最强”“终局”“完整链路”等无法由本次证据支持的词。
- 单次运行只描述本次结果，不外推长期成功率。
- 社交和媒体内容只补充使用体验，不替代官方能力和本地实测。
